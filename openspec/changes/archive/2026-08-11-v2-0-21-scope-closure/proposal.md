# Close the v2.0.21 specification scope

## Why

The completed v2.0.21 change projected its requirement into the canonical CI
diagnostics specification, but its immutable Commitment omitted that canonical
path. ETHOS therefore correctly rejected the archived generation as uncovered.

## What changes

- bind the already-present canonical specification path to a new atomic Change;
- add no product, release, provider, or runtime behavior;
- preserve the immutable v2.0.21 implementation and proof history.

## Non-goals

- no compatibility layer or duplicate specification;
- no rewrite of the archived v2.0.21 Change;
- no Forge, installation, or runtime claim.
