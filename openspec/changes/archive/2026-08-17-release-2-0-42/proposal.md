## Why

The accepted tree removes an obsolete repository evidence taxonomy and aligns
document names with their actual semantic owners. Version 2.0.41 does not
contain that convergence, so the exact accepted source needs a new immutable
patch identity.

## What Changes

- Advance the sole version carrier from 2.0.41 to 2.0.42.
- Record the removal of Claims, Chronicle, and the empty `evidence/` authority.
- Record the documentation information-architecture convergence.
- Prove and archive the exact source before independent Forge publication.

## Impact

This release changes repository governance, quality contracts, and
documentation organization. It does not change proxy protocol behavior,
provider routing, client configuration, credentials, or conversation state.
