## Why

The accepted source after 3.1.11 fixes a real Codex replay failure and removes a
parallel Ruff policy owner, but those changes are not yet available as an
installable release. A new patch release is required because published 3.1.11
bytes and provenance are immutable.

## What Changes

- Publish the accepted Responses item authority that safely removes a complete
  Codex-local shell call/output pair while preserving current dialogue.
- Publish the bounded distinction between recognized schema drift and genuinely
  unknown Responses item types.
- Publish the already accepted single Ruff configuration authority.
- Advance the release identity and changelog to 3.1.12 without rewriting any
  earlier tag or release.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. The product behavior was specified and accepted by the archived
`response-item-authority` Change; this Change packages that accepted behavior.

## Impact

`VERSION`, `CHANGELOG.md`, release metadata, native assets, signed tag, both
Forge release projections, and the installed native service are affected.
Provider routing, credentials, client configuration, and conversation storage
are unchanged.
