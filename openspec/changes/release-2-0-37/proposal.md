## Why

The portable native-command lifecycle is complete and locally proved as
version 2.0.37. A dedicated release generation gives that product state one
unambiguous proof and delivery identity without rewriting prior releases.

## What Changes

- Record 2.0.37 as the sole release identity already carried by `VERSION` and
  `CHANGELOG.md`.
- Prove and archive the exact release source before publication.
- Publish GitLab and GitHub independently from equivalent verified product
  trees.

## Impact

This generation adds release evidence only. It does not alter provider
configuration, proxy protocol behavior, Codex state, or the installed runtime
before a verified release asset is explicitly installed.
