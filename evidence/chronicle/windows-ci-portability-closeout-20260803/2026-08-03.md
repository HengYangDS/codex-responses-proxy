# Windows CI portability closeout

## Fact

GitHub main jobs 91552581568 and 91552581578 failed because the launchd test
constructed an expected path with a literal slash. The same jobs spent about
eleven minutes in the real handoff suite after `pids_naming_path()` began
discarding its batch process command lines and invoking PowerShell/CIM for every
PID.

## Evidence

A focused RED test failed before implementation when per-PID re-query was
forbidden. After the repair, Python 3.12, 3.13, and 3.14 process and macOS
focused tests pass, and the real handoff integration passes on macOS. The full
repository gate passed with 96.78 percent combined coverage and 1,644 of 1,730
branches covered, or 95.03 percent. The complete 3.12-3.14 compile/test matrix
also passed. Hosted CI, publication, installation, and runtime acceptance
remain separate transitions.

## Boundary

The change reuses non-Darwin inventory command lines only for discovery.
Darwin keeps native argv parsing, and signal paths retain live per-PID identity
revalidation immediately before mutation.
