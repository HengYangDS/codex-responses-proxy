The source repair has one carrier contract:

- textual assistant history uses an assistant Easy Input Message with string
  content, not an incomplete output-message hybrid;
- synthesized agent history uses a deterministic JSON routing header followed
  by the concatenated visible text, refusal text, or omission marker;
- system, developer, user, and function/custom-tool outputs remain on validated
  input-content grammar, including replayable remote `input_image` blocks;
- provider item IDs, status, annotations, ciphertext, and output-only metadata
  are removed rather than invented;
- request and SSE sanitization insert the same stable marker when ciphertext
  removal would otherwise leave semantic-empty agent or tool content;
- the classified DMX HTTP 477 fallback preserves the same assistant-string and
  input-content contract during its single bounded retry.
