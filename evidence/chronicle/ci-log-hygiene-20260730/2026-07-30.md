# CI log hygiene observation

Date: 2026-07-30

The `v1.0.35` hosted jobs succeeded while their logs exposed three independent
diagnostics: a loopback `BrokenPipeError` traceback, a Python 3.14
`ResourceWarning` for an unclosed `HTTPError`, and a GitLab container pip
root-user warning. This observation establishes the repair scope; it does not
claim hosted acceptance for `v1.0.36`.

Local verification for the implementation candidate ran the repository quality
gate, the Python 3.12/3.13/3.14 compile-and-test matrix, release contracts, and
a separate forbidden-diagnostic scan. The official OpenSpec archive now records that local implementation proof. Hosted
CI, provider-native tags and Releases, installation, runtime identity, and final
repository-family records remain later external transitions.
