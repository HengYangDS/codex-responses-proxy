## Root cause and local mechanism proof

The GitHub self-hosted runner reuses its repository workspace. Provider history
projection moves `main` to a new provider-specific commit while the workspace
can remain detached at the previous commit. Checkout replaces the local branch
before attaching the new tip, so Git reports the temporarily unreachable old
revision.

A disposable Git reproduction proved that retaining the old `HEAD` under
`refs/codex-dmx-proxy/runner-checkout-retained` removes the warning without
changing the selected checkout. Deleting the ref immediately afterward left no
ref residue. Advice suppression was rejected because it hides diagnostics and
does not remove the warning's first line.
