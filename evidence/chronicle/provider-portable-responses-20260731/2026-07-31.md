  stored-item and reasoning/search replay, provider item IDs, and opaque
  reasoning, agent, and tool-output ciphertext before upstream I/O.
- Text dialogue, agent routing context, complete function/custom-tool pairs, and
  replayable remote images remain; encrypted-only retained content receives an
  explicit omission marker. Unknown or malformed replay is rejected locally.

  477 recovery and cooldown are scoped only to the DMXAPI route. Upstream
  overrides accept only credential-free absolute HTTPS origins.

  later replay. Real handoff subprocess tests use an external test-only
  sitecustomize hook for their owned HTTP upstream instead of weakening the
  released HTTPS-origin rule.
